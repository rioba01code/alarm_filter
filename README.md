# Alarm Filter

An AI-powered SCADA Alarm Filtering and Reporting Platform.

## Tech Stack

- React (Frontend)
- FastAPI (AI & APIs)
- Spring Boot (Enterprise Backend)
- PostgreSQL (Database)

## Planned Features

- Upload SCADA alarm files (CSV/Excel)
- Intelligent alarm filtering
- Alarm prioritization
- Root cause analysis
- Reporting dashboard
- Email notifications
- Predictive maintenance
- Role-based access control
